# Analyse des transactions Bitcoin

## 1. Présentation du projet
Ce projet individuel porte sur l'analyse et la compréhension des transactions Bitcoin.

## 2. Objectif
Comprendre comment les transactions Bitcoin sont enregistrées, vérifiées et sécurisées sur la blockchain grâce à la cryptographie et au réseau décentralisé.

## 3. Méthodologie
- Présentation du fonctionnement des transactions Bitcoin.
- Étude du rôle du réseau blockchain.
- Analyse des informations d'une transaction (TxID, frais et confirmations).

## 4. Résultat attendu
Comprendre comment la blockchain assure la traçabilité et la transparence des transactions.

## 5. Outils utilisés
- Bitcoin TestNet4
- Mempool
- Wasabi Wallet
- GitHub Desktop
- Visual Studio Code
